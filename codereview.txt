## 🔴 **Critical Issues**

### 1. **Hardcoded Plugin Path (Security & Portability)**
````javascript path=src/edit.js mode=EXCERPT
const pluginUrl = window.location.origin + '/wp-content/plugins/NewOSM';
````

**Problem:** This breaks if:
- WordPress is in a subdirectory
- Plugin folder is renamed
- Site uses custom `wp-content` directory

**Solution:** Pass the plugin URL from PHP via `wp_localize_script`:

```php
// In newopm.php
function newopm_enqueue_editor_assets() {
    wp_localize_script('newopm-osm-map-editor-script', 'newOpmData', array(
        'pluginUrl' => NEWOPM_PLUGIN_URL
    ));
}
```

```javascript
// In edit.js
const pluginUrl = window.newOpmData?.pluginUrl || '';
```

### 2. **Missing Nonce Verification**
````php path=newopm.php mode=EXCERPT
// phpcs:ignore WordPress.Security.NonceVerification.Recommended
if (isset($_GET['settings-updated']) && $_GET['settings-updated']) {
````

**Problem:** While the comment acknowledges it, WordPress settings pages should verify nonces.

**Solution:** WordPress handles this automatically via `settings_fields()`, but the comment is misleading. The code is actually correct.

### 3. **REST API Public Access**
````php path=newopm.php mode=EXCERPT
'permission_callback' => '__return_true' // Public access for reading defaults
````

**Problem:** Anyone can read your default settings. While not highly sensitive, it's unnecessary exposure.

**Solution:** Restrict to authenticated users:
```php

```

## ⚠️ **Major Issues**

### 4. **Nominatim API Rate Limiting**
````javascript path=src/edit.js mode=EXCERPT
const response = await fetch(
    `https://nominatim.openstreetmap.org/search?format=json&q=${encodeURIComponent(searchQuery)}&limit=1`,
    {
        headers: {
            'User-Agent': 'WordPress-NewOSM-Plugin/1.0'
        }
    }
);
````

**Problem:** 
- No rate limiting implementation
- No caching
- Violates Nominatim usage policy (max 1 request/second)
- Could get your IP banned

**Solution:** 
1. Implement debouncing (wait 1 second between requests)
2. Add caching for repeated searches
3. Consider using a proxy endpoint in PHP to control rate limiting
4. Add error handling for 429 (Too Many Requests)

### 5. **Missing Error Boundaries**
The React components have no error boundaries. If Leaflet fails to load or throws an error, the entire editor could crash.

**Solution:** Add React error boundary:
```javascript
class MapErrorBoundary extends React.Component {
    state = { hasError: false };
    
    static getDerivedStateFromError(error) {
        return { hasError: true };
    }
    
    render() {
        if (this.state.hasError) {
            return <div>Map failed to load. Please refresh.</div>;
        }
        return this.props.children;
    }
}
```

### 6. **Memory Leaks in Event Listeners**

**Problem:** Event listeners are added but never removed if the map is destroyed/re-initialized.

**Solution:** Store references and clean up:

## 📊 **Performance Concerns**

### 21. **Map Re-renders**
````javascript path=src/edit.js mode=EXCERPT
setMapKey(prev => prev + 1); // Force map to re-center
````

**Problem:** Completely destroys and recreates the map. This is expensive.

**Solution:** Use `map.setView()` instead:
```javascript
const map = useMap();
useEffect(() => {
    map.setView([latitude, longitude], zoom);
}, [latitude, longitude, zoom]);
```

### 22. **No Debouncing on Marker Drag**
Every pixel of drag triggers a reverse geocoding request.

**Solution:** Debounce the `fetchAddress` call:
```javascript
import { debounce } from 'lodash';
const debouncedFetchAddress = debounce(fetchAddress, 500);
```

### 23. **Leaflet Loaded from CDN**
````php path=newopm.php mode=EXCERPT
wp_enqueue_script(
    'leaflet-js',
    'https://unpkg.com/leaflet@1.9.4/dist/leaflet.js',
````

**Problem:** 
- External dependency (fails if unpkg is down)
- No SRI (Subresource Integrity) hash
- Privacy concern (external request)

**Solution:** Bundle Leaflet locally or add SRI:
```php
wp_enqueue_script(
    'leaflet-js',
    'https://unpkg.com/leaflet@1.9.4/dist/leaflet.js',
    array(),
    '1.9.4',
    array(
        'in_footer' => true,
        'integrity' => 'sha384-...',
        'crossorigin' => 'anonymous'
    )
);
```
